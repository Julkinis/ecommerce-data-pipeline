# E-commerce Data Pipeline

Учебный проект по построению ETL-пайплайна для обработки данных электронной коммерции и подготовки аналитических метрик.

## Цель проекта

Автоматизировать генерацию и загрузку заказов, проверять качество данных и подготавливать метрики для аналитического дашборда.

## Архитектура

Apache Airflow оркестрирует ежедневный DAG:

1. `generate_orders` — генерирует тестовые данные о заказах.
2. `load_orders` — загружает заказы в PostgreSQL с защитой от повторной загрузки.
3. `check_data_quality` — проверяет целостность данных и корректность выручки.

PostgreSQL хранит данные о товарах и заказах. Представление `daily_sales` агрегирует ежедневные показатели для Apache Superset.

## Данные и аналитика

Используются синтетические данные.

- `products` — товары, категории и цены.
- `orders` — даты заказов, товары, количество, статусы и выручка.
- `daily_sales` — ежедневные метрики заказов, выручки и среднего чека.

## Контроль качества данных

DAG проверяет:
- наличие связанных товаров для заказов;
- соответствие выручки цене товара и количеству.

Уникальное ограничение на `source_order_id` и `ON CONFLICT DO NOTHING` защищают от повторной загрузки заказов.

## Безопасность

Локальный файл `.env` с паролями и секретами не должен попадать в репозиторий. Для настройки используется `.env.example`. Не публикуйте реальные пароли, токены или ключи.
